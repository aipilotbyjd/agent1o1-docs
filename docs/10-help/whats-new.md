# What's new

Recent improvements, newest first.

## November 2026

### Reliability

- **Maintenance mode is clearer.** During maintenance, automated runs are skipped and the app shows a read-only message.
- **Stuck steps recover.** If a playbook step is left running because a background worker was lost, it is now recovered instead of staying stuck.

### Pages

- **New page blocks:** code, pricing, embed, gallery, compare, progress, social and timeline blocks, plus steps and features blocks, with display settings for each block.
- **Copy a page between workspaces.**
- **Hide a page from search engines.**

### Agents

- **Follow-ups, questions, conversation recall and cited sources** for agents.

### AI providers

- **One-click AI provider connect**, and using your own key is now the default.
- **Personal assistants stay off team keys** unless the workspace allows it. See [AI providers and your own keys](../06-apps-and-keys/ai-providers.md).

### Lists and speed

- **Large lists load in pages.** Playbooks, agents, conversations, versions, memories, runs, skills and pages now load in pages.
- **Playbook lists can be filtered and sorted** by the server.

### Security

- **Connecting an app** can only be finished by the member who started it.
